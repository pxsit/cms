HTML before the PDF button

HTML and CSS are supported in a separate sandboxed block. JavaScript, forms, and access to the contest page are disabled. Add your own fonts, spacing, headings, and colors with a <style> block.

Example: a quiet, playful introduction
<style>
body { margin: 0; padding: 24px; background: #faf6f2;
       color: #59494b; font: 18px/1.7 Georgia, serif; }
h2 { font-size: 25px; font-weight: normal; }
</style>
